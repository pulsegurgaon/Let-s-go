# 🎥 AI Video Production Cloud Factory

A mobile-controlled, cloud-powered video generation pipeline. This system uses **Groq (Llama 3.3)** to expand simple ideas into 500+ word cinematic prompts, renders them using **LTX-Video** on a high-end GPU, and automatically uploads the results to **Google Drive**.
